# Executive deliverable

Produce a finished, on-brand JointGlow document from material the user has approved.

## 1. Pin down the brief

Settle these, asking only for what you can't infer:
- Audience: investor, partner clinic, referring physician, board, internal team.
- The one decision or action the document should produce.
- Format: deck, memo, spreadsheet or web page.
- Length.
- Source material: where it lives (files, Notion, Drive).

Use only the approved sources. If something important is missing, such as a metric, a date or a price, mark it `[needs source]` and list it at the end. Never fill it in.

## 2. Pick the tool

- Deck: the `pptx` skill. Memo or proposal: the `docx` skill. Model or table: the `xlsx` skill, using live formulas, never hard-coded totals. PDF: the `pdf` skill.
- Shareable web page or dashboard: an Artifact.

## 3. Structure

- **Deck**: title → the ask or main message → problem → JointGlow's approach → evidence (cited) → the plan and numbers → risks → the ask again. One idea per slide, with a headline that states the point.
- **Memo**: bottom line first (decision needed) → background → options with trade-offs → recommendation → next steps.
- **Model**: an Inputs tab (assumptions, each with a source or marked as an assumption) → Calculations → Summary. Include a check row for totals.

## 4. Apply the brand

Use the logos in `brand/`, Poppins (fallback Helvetica Neue or Arial), and charcoal `#373535` with gold `#ddb529` and the gradient `#edda5a` to `#de9c2e`. Use generous white space. Charts use charcoal and gold first, then greys.

## 5. Verify before handing over

- Decks and docs: render them (convert to PDF or images with LibreOffice) and look at every page for overflow, clipping and leftover placeholder text.
- Spreadsheets: recalculate with LibreOffice and check that totals tie out and no cell shows an error.
- Check each number against its source.

In your reply, give the file, the list of `[needs source]` gaps, and what you checked.
